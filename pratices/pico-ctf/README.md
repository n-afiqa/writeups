## picoCTF

Write-ups for practice challenges from picoCTF, the cybersecurity learning platform now known as CyLab.

Challenges are organized by category for easier navigation.

| Category | Description |
|---|---|
| [Cryptography](cyptography/README.md) | Encryption, decryption, hashing, and encoding |
| [Forensics](forensic/README.md) | File analysis, metadata, steganography, and network traffic |
| [General Skills](general/README.md) | Command-line tools, scripting, and basic computing |
| [Reverse Engineering](reverse-engineering/README.md) | Program analysis and binary inspection |
