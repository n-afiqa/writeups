## General

General challenges cover fundamental cryptography concepts, including data encoding, byte and integer conversions, and basic XOR operations using Python.

### Challenges Lists

| Challenge | Concept | Description |
|---|---|---|
| ASCII | Integer → ASCII | Convert an array of integers into ASCII characters using `chr()`. |
| Base64 | Hex → Bytes → Base64 | Convert hexadecimal data into bytes and encode it using Base64. |
| Bytes and Big Integer | Integer → Bytes → String | Convert a large integer back into its original byte representation. |
| Favourite Byte | Hex → Bytes → Single-byte XOR | Brute-force all possible single-byte XOR keys to recover the plaintext. |
| Hex | Hex → Bytes → String | Decode hexadecimal strings into readable text. |
| XOR Properties | XOR Key Cancellation | Apply XOR properties to recover plaintext by cancelling known keys. |
| XOR Starter | String → ASCII → XOR → String | Apply XOR to each character using an integer key and reconstruct the resulting string. |

## Key Topics Covered

- ASCII and character encoding
- Hexadecimal and Base64 representations
- Bytes and big integer conversions
- Single-byte XOR encryption
- XOR properties and key cancellation
- Brute-force techniques
- Python cryptographic utilities
