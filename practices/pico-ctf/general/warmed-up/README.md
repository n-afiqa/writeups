## Warmed Up

### Objective:
Covert hex number into eciuma number

### Solution:
The given hexadecimal number is 0x3D.
In hexadecimal, D represents 13 in decimal.

0x3D = (3 × 16¹) + (13 × 16⁰); D = 13
     = 48 + 13
     = 61
